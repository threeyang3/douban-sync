# 2.3.0 发布说明

## 模板实时预览

- 模板设置明确说明内置、文件、自定义三种来源的修改方式。
- 内置模板点击“预览样式”，文件和自定义模板点击“编辑并预览”：左侧源码，右侧示例笔记，输入后自动刷新。
- 七种条目类型提供示例数据，预览跟随当前主题、数组格式和自定义字段设置，支持封面、表格、callout 和笔记属性查看。
- 提示 YAML 格式错误及未解析变量；窄窗口自动上下排列。
- 文件模板支持保存到原文件，外部修改会阻止覆盖；取消编辑不保存。
- 动态查询和脚本展示为代码，预览不代表第三方插件运行后的完整结果。

## 导入与数据保护修复

- 保留导入预览中取消勾选的条目状态，修复属性别名映射。
- 记录、感想正文纳入逐字段差异对比与合并。
- 原子更新最新笔记内容，保护预览后新增的编辑。
- 修正 frontmatter 空值、块值、字符串及带引号属性名的更新。
- 修正模板文件及同步报告的扩展名，支持隐藏目录备份恢复。
- 强制同步时遇到再次冲突的同名文件，继续选择安全路径，避免覆盖其他条目。

## 验证

插件生产构建、文档构建和自动化测试通过；已在本地 Obsidian Sandbox 验证实时预览、文件保存、外部修改保护，以及导入和备份相关流程。
