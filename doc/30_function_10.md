# 功能
- ☑️ 导入电影、电视剧、书籍、音乐、游戏、日记
- ☑️ 同步个人听过/看过的电影、电视剧、书籍、音乐、游戏
- ☑️ 导入个人的评论,评论时间,阅读状态,个人评分
- ☑️ 支持保存封面至本地/图床
    - ⬜ 支持图床自定义
- ☑️ 支持自定义参数
- ☑️ 自定义参数支持导出 JSON、合并导入、覆盖导入
- ☑️ 内置基础/简洁/同步模板预设
- ☑️ 强制替换同步时继承旧笔记 frontmatter 字段
- ☑️ 用户数据导出（自定义属性 + 正文分区 → JSON）
- ☑️ 用户数据导入（JSON → 合并到本地文件，支持三种合并策略）
- ☑️ 强制同步数据保护（保留自定义属性、记录、感想）
- ☑️ 支持移动端导入
- ⬜ 支持使用AI大模型ChatGPT、Deepseek、Ollama分析导入
