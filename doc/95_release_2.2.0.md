# 2.2.0 发布说明

2.2.0 重点吸收上游稳定性改进，同时保留本项目已有的同步预览、备份、数据保护和模板工作流。

## 新增功能

- 桌面端和移动端二维码登录，手动 Cookie 登录继续保留
- 多行豆瓣 URL 批量导入，支持去重、进度、取消和失败隔离
- 舞台剧独立解析和模板，兼容顶层信息与多个演出版本
- 数组字段长度限制，可控制演员、导演、作者、别名等字段体积
- `imageName` 和图书 `popularComments` 模板变量
- 创建后自动打开笔记设置
- 模板变量点击复制

## 稳定性

- 网络请求增加超时、有限重试、重定向限制和主动中止
- 登录页、验证页、禁止访问页和异常空页面不会生成空白笔记
- 单条导入失败不会阻塞同步或批量任务
- 搜索页 JSON 响应、电影/电视剧类型识别和同名文件冲突已加强处理

## 安全

- 普通日志不再输出 Cookie、Authorization 或完整请求内容
- 登录相关 URL 参数自动脱敏
- 跨非豆瓣域重定向会移除敏感请求头

## 升级建议

- 升级前备份 Vault，尤其是启用强制替换同步的用户
- 旧配置会自动补齐新增默认值
- 二维码登录若受网络限制，可继续使用手工 Cookie 登录
