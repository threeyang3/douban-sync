# 设置
- 设置豆瓣账号(可选，可使用少部分功能)
- 设置导入模板(可选，不设置的情况下使用默认模板)
- 设置导入路径(可选，不设置的情况下使用默认路径)

## 自定义字段

- 可以在“自定义字段”中新增模板变量
- 支持 `导出JSON` 备份当前自定义字段
- 支持 `合并导入` 与 `覆盖导入`
- 合并导入会按 `参数名称 + 生效类型` 去重

## 模板预设

- 模板设置区提供三套内置模板：`基础模板`、`简洁模板`、`同步模板`
- 可直接复制预设内容
- 可一键写入模板文件
- 如果目标模板文件已存在，会先要求确认，不会静默覆盖

## 同步替换继承

- 在同步窗口开启”替换同名文档”后，可继续开启”继承旧笔记字段”
- 当前版本仅继承旧笔记 frontmatter 中指定字段
- 默认建议填写：`tags, aliases`
- 插件会先生成新笔记，再补入继承字段，最后才删除旧文件

## 数据保护

- 强制替换同步时，插件会自动保留用户在旧笔记中的自定义数据
- 设置区提供三个独立开关：
  - **保留自定义属性**：保留旧笔记 frontmatter 中非标准字段（如自定义评分、分类等）
  - **保留「记录」分区**：保留旧笔记正文中 `## 记录` 部分的内容
  - **保留「感想」分区**：保留旧笔记正文中 `## 感想` 部分的内容
- 默认全部开启，建议保持开启以避免数据丢失

## 用户数据导出/导入

- 命令面板搜索”导出豆瓣用户数据”或”导入豆瓣用户数据”
- 导出：扫描指定文件夹，将含 `doubanId` 的笔记的自定义属性和正文分区导出为 JSON 文件，按条目类型分组
- 导入：选择导出的 JSON 文件，选择合并策略后导入
- 合并策略：
  - **智能合并**：仅当本地值为空且导入值非空时覆盖
  - **本地优先**：不覆盖已有字段
  - **导入优先**：用导入值覆盖本地值
- 导入时如遇到本地 frontmatter 中不存在的字段，会逐条询问是否添加
