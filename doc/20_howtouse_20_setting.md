# 设置
- 设置豆瓣账号(可选，可使用少部分功能)
- 设置导入模板(可选，不设置的情况下使用默认模板)
- 设置导入路径(可选，不设置的情况下使用默认路径)

## 自定义字段

- 可以在“自定义字段”中新增模板变量
- 支持 `导出JSON` 备份当前自定义字段
- 支持 `合并导入` 与 `覆盖导入`
- 合并导入会按 `参数名称 + 生效类型` 去重

## 模板设置

每类条目（电影/书籍/音乐/电视剧/游戏/日记）的模板支持三种来源：

- **内置模板**：使用插件内置的同步模板（含用户状态字段），点击预览按钮可查看内容
- **从文件选择**：指定 Vault 中的 Markdown 文件作为模板
- **自定义内容**：在编辑器中直接编写模板内容，支持所有模板变量

每个模板行都有一个复制按钮，可将当前模板内容复制到剪贴板。

当前版本补充了两个高频操作：

- **另存为文件**：在模板预览或自定义模板编辑器中，可直接把当前模板内容保存成一个 `.md` 文件，并切换为“从文件选择”模式复用
- **恢复默认模板**：可一键切回当前类型的内置模板，避免自定义模板改坏后手工回退

## 同步替换继承

- 在同步窗口开启”替换同名文档”后，可继续开启”继承旧笔记字段”
- 当前版本会按“数据保护”设置继承旧笔记中的自定义 frontmatter 属性、`## 记录`、`## 感想`
- 插件会先生成新笔记，再补入继承数据，最后才删除旧文件

## 数据保护

- 强制替换同步时，插件会自动保留用户在旧笔记中的自定义数据
- 设置区提供三个独立开关：
  - **保留自定义属性**：保留旧笔记 frontmatter 中非标准字段（如自定义评分、分类等）
  - **保留「记录」分区**：保留旧笔记正文中 `## 记录` 部分的内容
  - **保留「感想」分区**：保留旧笔记正文中 `## 感想` 部分的内容
- 默认全部开启，建议保持开启以避免数据丢失

## 同步预览与备份

- 同步窗口新增 **同步预览**
- 开启“替换同名文档”后，点击“开始同步”会先展示预览，再确认是否真的执行
- 预览会统计：
  - 将创建多少条
  - 将替换多少条
  - 将跳过多少条
  - 增量同步中哪些条目会因为“已处理”而跳过
- 若已开启“强制替换前自动备份”，预览中会明确提示替换条目会先备份旧笔记
- 强制替换前的备份目录可在“高级 > 数据保护”中配置，默认目录为 `.tmp/obsidian-douban/backups`

## 配置导入导出

- 导出插件配置时，默认**不会包含登录 Cookie 和请求头**
- 如果确实需要完整迁移登录状态，可在高级设置中显式开启“导出配置时包含登录凭据”
- 导入配置时只会应用插件已知字段，未知字段会被自动忽略，降低错误 JSON 覆盖设置的风险

## 用户数据导出/导入

- 命令面板搜索”导出豆瓣用户数据”或”导入豆瓣用户数据”
- 导出：扫描指定文件夹，将含 `doubanId` 的笔记的自定义属性和正文分区导出为 JSON 文件，按条目类型分组
- 导入：选择导出的 JSON 文件，选择合并策略后导入
- 合并策略：
  - **智能合并**：仅当本地值为空且导入值非空时覆盖
  - **本地优先**：不覆盖已有字段
  - **导入优先**：用导入值覆盖本地值
- 导入时如遇到本地 frontmatter 中不存在的字段，会逐条询问是否添加
