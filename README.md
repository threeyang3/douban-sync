# Obsidian Douban Plugin

这是一款用于 Obsidian 的豆瓣数据导入与同步插件。它可以把豆瓣中的电影、电视剧、书籍、音乐、游戏、日记等条目信息整理为 Obsidian 笔记，并支持同步个人标记记录。

![background](./doc/background.png)

## 功能

- 搜索豆瓣条目并创建 Obsidian 笔记
- 按当前文件名或输入文本搜索条目
- 同步个人看过、想看、在看、读过、想读、在读、听过、想听、在听、玩过、想玩、在玩等记录
- 导入个人评分、评论、标记日期、状态和标签
- 保存封面到本地附件目录或图床
- 自定义笔记模板、文件路径和字段参数
- 自定义属性支持导出 JSON、合并导入、覆盖导入
- 内置 `基础 / 简洁 / 同步` 模板预设，可一键写入模板文件
- 模板来源选择：内置模板、从文件选择、自定义内容
- 模板支持预览、另存为文件、恢复默认模板
- 内置模板封面链接 `image: {{imageData.url}}`
- 强制替换同步时可继承旧笔记指定 frontmatter 字段
- 强制替换同步支持执行前预览、自动备份、结构化结果报告
- 配置导出默认排除登录凭据，导入配置按白名单校验
- 支持桌面端和移动端使用

## 使用

### 搜索导入

在 Obsidian 中输入 <kbd>Ctrl</kbd> + <kbd>P</kbd>，搜索 “豆瓣” 或 “Douban”，选择对应命令后使用。

![search_and_create](doc/img/search_and_create_note.gif)

### 同步记录

登录豆瓣账号后，可同步个人书影音和游戏记录到 Obsidian。

![Sync Data From Douban](doc/img/sync_data_from_douban.gif)

强制替换同步前，插件会先展示预览，列出将创建、替换、跳过的条目；如果你启用了自动备份，替换旧笔记前也会先保留备份副本。

## 设置

- 豆瓣账号：用于同步个人数据，部分功能需要登录后使用
- 导入模板：用于控制生成笔记的内容结构
- 导入路径：用于控制笔记保存位置
- 附件设置：用于控制封面图片保存位置

### 1.2.0 新增

- 自定义字段区新增 `导出JSON`、`合并导入`、`覆盖导入`
- 模板设置区新增内置模板预设，可复制内容或直接写入模板文件
- 同步弹窗新增”继承旧笔记字段”，默认建议继承 `tags, aliases`

### 1.4.0 新增

- 用户数据导出：将本地条目的自定义属性和正文分区（记录/感想）导出为 JSON
- 用户数据导入：从 JSON 导回，支持智能/本地优先/导入优先三种合并策略
- 强制同步数据保护：强制替换同步时自动保留用户的自定义属性和正文分区
- 数据保护设置：可独立开关自定义属性、记录分区、感想分区的保留

### 1.5.0 新增

- 模板设置 UI 重构：每类模板一行 dropdown（内置模板 / 从文件选择 / 自定义内容）+ 上下文按钮
- 模板编辑器：支持预览内置模板和直接编辑自定义模板
- 内置模板封面链接：frontmatter 新增 `image: {{imageData.url}}`
- 修复 tags 不再混入条目类型（book/movie 等）

### 2.1.x 同步安全增强

- 强制替换同步前新增预览确认，先看影响范围再执行
- 强制替换前支持自动备份旧笔记，备份失败时会中止危险替换
- 同步结果会额外生成结构化 JSON 报告，便于排查失败条目
- 配置导出默认不包含登录凭据，配置导入只接受插件已知字段
- 模板预览支持直接另存为文件，自定义模板支持恢复默认模板

## 安装

### 从 Obsidian 插件中心安装

1. 打开 Obsidian 设置
2. 进入第三方插件市场
3. 搜索 `obsidian-douban`
4. 安装并启用插件

### 手动安装

1. 从当前仓库的 Release 页面下载 `main.js`、`manifest.json`、`styles.css`
2. 将文件放入 Obsidian 仓库的 `/.obsidian/plugins/obsidian-douban/` 目录
3. 在 Obsidian 中启用插件

## 开发
